## command

- settings > General > Global (suggest better name)
  - options to choose global or local
    - global: current. share options across all
    - local: old. options for just that browser. if browser set to local. Ignore and global settings
      - time, weather, etc
  - import/export global
  - local as default
- Switching one browser to Local applies only to that browser. Other browsers set to Global remain in Global mode.

## goal

Add a “Settings scope” section under Settings → General with Local and Global modes, defaulting to Local. Each browser independently chooses and remembers its mode. Global mode retains the current shared dashboard settings. Local mode keeps settings specific to that browser and ignores global settings, including time and weather preferences. Switching a browser to Local or changing its local settings must not affect other browsers or shared global settings. Browsers set to Global remain in Global mode and continue using shared settings. Allow importing and exporting global settings.
