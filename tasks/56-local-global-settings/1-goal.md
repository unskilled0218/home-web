## command

- settings > General > Global (suggest better name)
  - options to choose global or local
    - global: current. share options across all
    - local: old. options for just that browser. if browser set to local. Ignore and global settings
      - time, weather, etc
  - import/export global
  - local as default

## goal

Add a “Settings scope” section under Settings → General with Local and Global modes, defaulting to Local. Global mode retains the current shared dashboard settings. Local mode keeps settings specific to that browser and ignores global settings, including time and weather preferences. Allow importing and exporting global settings.
