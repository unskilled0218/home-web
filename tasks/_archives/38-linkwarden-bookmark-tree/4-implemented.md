## Decisions

- Public configuration identity is derived from the stored encrypted record, avoiding a schema migration and distinguishing rapid same-URL saves. Stable folder IDs survive renamed labels and token rotation, while source transitions invalidate old data.
- Folder data and disclosure policy live in the controller; the view keeps keyed DOM nodes and uses native disclosure semantics. Expanded means the initial open policy, with explicit session toggles preserved per profile. Reload retains the saved mode and reapplies its defaults.
- Browser wire responses are bounded to 3 MiB, with separate 2 MiB server bookmark-data and 8 MiB normalized browser-content budgets. Limits produce clear errors/notices instead of silent tree flattening or indefinite loading.
- Authentication retirement applies only to committed-source reads; a failed provisional connection cannot retire the currently usable account. Source discovery and data validation use separate ownership rules, and both token renewal and mismatched-source rediscovery are bounded.
- Fullscreen visibility is independent of connection/disclosure state. Hidden fullscreen skips loading previously unseen folders caused only by viewport changes; already loaded content may refresh through the single existing owner.
