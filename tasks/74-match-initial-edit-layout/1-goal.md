## command

Match first Edit layout to the default layout; Edit layout currently shows a 3×2 layout.

## goal

When entering Edit layout without a saved custom layout, start from the dashboard's current default arrangement instead of rearranging widgets into a 3×2 grid. Preserve existing custom layouts and keep changes unsaved until the user chooses Save.
