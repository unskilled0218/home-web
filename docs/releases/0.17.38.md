## Changes

Show bounded sanitized local-verification logs while commands run, plus elapsed heartbeats and safe publication/runtime phases. Authenticated command output remains private; phase completion does not replace remote verification. The lock supervisor drains console output through execution and cleanup, so unread or closed pipes cannot hold the release lock. Stateful sanitation also protects failure diagnostics after truncation and suppressed sensitive blocks. Mandatory checks, early non-bootstrapping ARM64 readiness, immutable runtime gates, and deployment behavior remain unchanged. No live publication or privileged setup was performed during implementation.
