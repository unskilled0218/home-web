## Changes

Local dashboards now follow Global's shared image selection by default, including existing profiles without an explicit choice. **Settings → Images → Show the same image as Global** can be disabled and saved for independent Local playback. Explicitly saved off choices survive reload, scope changes, and unrelated Local saves. Local presentation, weather, layout, and other preferences remain independent. Local order/interval are retained but disabled while following. Source changes clear the previous frame until replacement loading succeeds; transient failures within an unchanged source retain the last-good image. Shared playback follows server selection rather than frame-perfect synchronized transitions. Global import messaging now distinguishes unchanged Local settings from shared playback changes; transfer schemas and server APIs remain unchanged. See [settings scope](../settings-scope.md) and [NFS backgrounds](../nfs-backgrounds.md).
