## Changes

Edit layout now omits visibility-disabled widgets from frames, widget choices, and layer rows. Visibility follows the selected editing profile and fullscreen overrides, even when that profile is inactive. Hidden widgets retain their rectangles and saved layer slots; layer commands reorder enabled widgets only. Empty profiles remain safe to open and cancel, while visibility changes cancel a disappearing widget's drag and discard uncommitted numeric text without rebasing completed drafts. Automatic no-op saves, six-widget storage, and Local/Global layout ownership remain unchanged. See [layout editing](../dashboard-layout.md).
