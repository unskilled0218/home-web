## Changes

Bookmarks, Home Assistant, and Wake-on-LAN now support independent desktop/mobile scales from 0.5 to 2. Save each category to its selected Local/Global store. Text, sensor readings, and action labels scale in Automatic and Custom layouts without rewriting saved geometry or restarting unrelated clock/photo owners. Older saved records and complete version-1 exports default only absent new scales to 1. See [dashboard settings](../dashboard.md), [settings scope](../settings-scope.md), and [import/export](../settings-import-export.md).
