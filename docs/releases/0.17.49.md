## Changes

Release authentication now defaults to `~/.config/token/git` instead of `~/.config/git/token`. Provision the private token file at the new location before publishing; the workflow does not move credentials or fall back automatically. Explicit `GIT_TOKEN` file-path overrides and custom `token_file` configuration remain supported, with the same credential security checks and credential-free local validation. Independent SSH/Git authentication is unchanged. See [publishing releases](../releases.md).
