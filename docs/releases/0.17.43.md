## Changes

Entering Edit layout on the active Automatic profile now keeps the live default arrangement, typography, and caption placement instead of projecting a grid. Frames track measured widget bounds; actual edits or explicit Custom selection create bounded Custom geometry. Unchanged rounded numeric observations remain no-ops even for short or offscreen widgets. Existing Custom layouts, inactive-profile editing, General Local/Global ownership, and explicit Save/Cancel remain supported. See [layout editing](../dashboard-layout.md).
