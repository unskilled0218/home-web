## Changes

Added **Images → Show image**, enabled by default and saved through the existing Images Local/Global scope. Hiding images hides foreground photos, blurred backdrops, transitions, and filename captions while retaining the solid background color and widgets. Playback, preloading, and selection continue unchanged; showing images restores the current selection. Older saved records, confirmed caches, and version-1 imports default only the missing visibility field to `true`, preserving explicit `false` and strict validation. See [dashboard preferences](../dashboard.md), [settings scope](../settings-scope.md), and [Global transfers](../settings-import-export.md).
