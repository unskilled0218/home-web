## Changes

Fixed weather-proxy verification on Node 26 by giving the isolated HTTPS proxy fixture a certificate-validated DNS hostname and separating native subdomain comparisons from the weather transport's wildcard-apex contract. Native and weather cases now run as independent subtests, including TLS rejection checks, and fetch failures include their nested cause stack. Production transport behavior, dependencies, TLS validation, and release gates are unchanged. See [weather proxy guidance](../dashboard.md#weather).
