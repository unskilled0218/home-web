## Changes

Support package linking on Gitea `28.2.0` after verifying its exact upstream association contract. New links require matching `/api/v1/version` and `/swagger.v1.json` Gitea title/version evidence, not merely a version allowlist. Stable `1.25.x` behavior and read-only existing links remain unchanged. Hidden/foreign associations cannot authorize replacement; one-POST reconciliation and exact final readback remain required. All writers must still be serialized because the server's database update is not compare-and-set. No live publication or package mutation was performed during implementation.
