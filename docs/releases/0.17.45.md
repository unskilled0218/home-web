## Changes

Removed General's Local/Global selector while retaining the seven widget categories' selectors and existing saved layout ownership. Explicit Global import/export now works even when every category is Local. Valid file selection prepares raw Global revisions without applying settings or starting continuous Global preference polling; Reload retries failed preparation or refreshes a conflict baseline. Imports preserve Local records and category choices, and retain strict revision, draft, and action guards. See [settings scope](../settings-scope.md), [Global transfers](../settings-import-export.md), and [layout editing](../dashboard-layout.md).
