## Changes

Check the selected Buildx builder's running AMD64/ARM64 capacity before dependency installation and tests, then recheck after local verification against the original plugin identity. Both inspections omit bootstrap: stopped or missing backends require separate administrator preparation. Mandatory verification and immutable-image runtime checks remain unchanged; advertised platforms do not certify ARM64 execution. No live publication or privileged host setup was performed during implementation.
