## Changes

Choose Local or Global independently for General, Time, Weather, Calendar, Bookmarks, Home Assistant, Wake-on-LAN, and Images. Category saves preserve unrelated raw settings; tab switches retain separate drafts. Existing whole-dashboard choices seed all categories without copying preferences. Widget visibility/fullscreen controls now live in their owning panels, direct layout editing follows General, and Local Images retains its optional Global following. Server resources use service-specific Global mutation guards. Writes revalidate the persisted category map before dispatch; General offers confirmed map-only recovery for corrupt choices. Global import/export retains its existing file/API contract and operates on raw Global data, never the mixed dashboard projection. See [settings scope](../settings-scope.md).
